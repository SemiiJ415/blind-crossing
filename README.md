# Blind Crossing

Blind Crossing is a two-player strategy game built with HTML, CSS, and JavaScript.

Players race across a hidden-danger grid while avoiding randomly placed bombs. Every move is a risk, and every round becomes a battle of memory, strategy, and bluffing.

## Features
- turn-based gameplay
- randomized hidden bombs
- bomb penalties
- private player information
- bomb detector ability
- replayable rounds

## Tech Stack
- HTML
- CSS
- JavaScript
